# React Hooks – 🕝 Counter Practice

## 📌 About the Project

This project was created to practice and understand three essential React Hooks: `useState`, `useEffect`, and `useReducer`.
Each hook is demonstrated through a different counter, highlighting its main features and use cases.

### 1. useState Counter
- **Increase:** Increments the counter by one.
- **Reset:** Resets the counter to zero.

### 2. useEffect Counter
- **Increase:** Increments the counter by one.
- **Reset:** Resets the counter to zero.
- **Feedback Message:** Displays a message when the counter is increased.

### 3. useReducer Counter
- **Increase:** Increments the counter by one.
- **Decrease:** Decrements the counter by one.
- **Reset:** Resets the counter to zero.

## 🎯 Goals

- Understand how `useState` manages component state.
- Learn how `useEffect` handles side effects in React.
- Understand how `useReducer` manages state through actions and a reducer function.
- Practice handling user interactions and updating the UI dynamically.
